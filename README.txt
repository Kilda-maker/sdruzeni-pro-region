Sdružení pro region – statický web
==================================

Obsah složky:
- index.html      hlavní stránka
- styles.css      vzhled a responzivní rozložení
- script.js       mobilní menu, animace a filtr kandidátů
- assets/         logo a obrazové výřezy z dodaného volebního letáku

Lokální spuštění:
1. Otevřete index.html přímo v prohlížeči, nebo
2. spusťte ve složce například: python -m http.server 8000
   a otevřete http://localhost:8000

Poznámky:
- Kontaktní údaje jsou záměrně označeny jako [doplnit], protože v dodaných materiálech nebyly uvedeny.
- Obsah programu a kandidátní listiny je převzat z dodaného letáku a Word dokumentu.
